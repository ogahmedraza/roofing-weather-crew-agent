# Security

Please do not publish credentials, API keys, tokens, private customer data, email content, or production identifiers in issues, pull requests, or workflow exports.

If you find a security problem in this repository, report it privately to the repository owner through GitHub rather than opening a public issue. Remove or rotate any exposed credential immediately.

Before importing a workflow, review every node, expression, webhook, pinned item, and external URL and connect only your own accounts.
